# Exploración Apple Design

Propuesta visual comparativa para la landing principal. Conserva el contenido,
los recursos de marca y las fuentes de VecinoClub; explora una superficie oscura,
más espacio y transiciones discretas. Se puede abrir en `/apple-design/` cuando
`landing/` se sirve como raíz estática.

La página no usa build ni dependencias del frontend. El JavaScript activa las
entradas al desplazarse y maneja la galería vertical de ejemplos de premios;
respeta `prefers-reduced-motion`.
